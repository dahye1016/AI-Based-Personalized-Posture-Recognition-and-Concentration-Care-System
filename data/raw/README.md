# data/raw — 32ch 옛 좌우 기준 데이터 (학습 미사용)

작성 2026-10-22 · 예원

## ⚠️ 이 폴더의 CSV 29개는 학습에 쓰지 않는다

2026-10-22 에 `lib/models/sensor_layout.dart` 와 `ml/collect_data.py` 의 좌우 기준을
**매트를 뒤집어 재설치한 뒤의 64ch 실측**에 맞춰 바꿨다.
이 폴더의 32ch 파일은 전부 **바꾸기 전(옛) 기준**으로 저장돼 있어 좌우가 반대다.

| | 옛 기준 (이 폴더) | 새 기준 (현재 코드, `data/raw_64ch/`) |
|---|---|---|
| ch0~4 | 오른 엉덩이 | 왼 엉덩이 |
| ch24~27 | 오른 무릎 | 왼 무릎 |
| ch28~31 | 왼 무릎 | 오른 무릎 |

**학습에는 `data/raw_64ch/` 만 사용한다.**

★ `ml/augment_data.py` 의 `--raw-dir` 기본값은 아직 `data/raw` 다.
**옵션 없이 그대로 실행하면 이 폴더의 옛 데이터를 읽는다.**

## 근거

다리 꼬기 파일에서 무릎 두 묶음의 평균을 비교했다 (작업 30 조사, 2026-10-22).
`cross_leg_right` 는 오른 무릎이 떠서 0 에 가까워야 한다.

| 묶음 | 파일 수 | 추가 커밋 | cross_leg_right 에서 0 에 가까운 쪽 |
|---|---|---|---|
| `yewon_*` | 8 | 6c7333e (08-16), ef76c09 (08-29) | ch24~27 → 옛 기준 |
| `aro_*` | 6 | 9339141 (08-16) | ch24~27 → 옛 기준 |
| `dahye_*` | 8 | a450543 (08-16), ef76c09 (08-29) | ch24~27 → 옛 기준 |
| `aro0921_*` | 7 | 7ea23fd (09-21) | ch24~27 → 옛 기준 (보정 후 저장, 아래 참고) |
| (비교) `data/raw_64ch/*` | 28 | 27c67e4 (10-18) | ch28~31 → 새 기준 |

27c67e4 커밋 메시지에도 "이 데이터는 매트를 뒤집은 뒤 수집" 이라고 적혀 있다.
다리 꼬기 이외 자세 파일은 따로 검증하지 않았다 (같은 수집 세션이라 같은 기준으로 본다).
매트가 정확히 언제 뒤집혔는지(또는 교체됐는지)는 확인 못 함.

## 지우지 않고 보존하는 이유

- 3인(예원·아로·다혜) 실측 원본이고 다시 받을 수 없다.
- 매뉴얼 합격 기준 수치(좌우 균형 %, 무릎 0 등)의 근거 데이터다.
- 아래 좌우 반전을 적용하면 새 기준 데이터로 되살릴 수 있다.

## 쓰려면 — 좌우 반전 순열이 필요하다

채널 순서에 `ml/augment_data.py` 의 `FLIP_INDEX` 를 적용하면 새 기준이 된다
(가로 줄 세 개를 각각 통째로 뒤집기: ch0~9 / ch10~23 / ch24~31).

★ 이때 **라벨은 바꾸지 않는다.** `Recording.flip()` 은 증강용이라 라벨까지
스왑(`cross_leg_right` ↔ `cross_leg_left` 등)하므로 그대로 쓰면 안 된다.
채널만 뒤집어야 한다.

## ⚠️ aro0921 이중 보정 금지

`aro0921_*` 7개는 수집 당시 매트가 반전돼 있어, **이미 한 번 좌우를 뒤집어 옛 기준으로
보정한 뒤** 저장됐다 (`aro0921_NOTE.md`, 커밋 7ea23fd).

- 지금 파일 상태는 다른 32ch 파일과 같은 **옛 기준**이다. 새 기준으로 쓰려면 다른 파일과
  똑같이 반전을 **한 번만** 적용한다.
- 반전은 두 번 적용하면 원래대로 돌아간다. "원본이 원래 새 방향이었으니 그대로 쓰자"
  하고 건너뛰거나, 보정을 되돌린 뒤 또 뒤집는 식으로 겹쳐 적용하지 말 것.
