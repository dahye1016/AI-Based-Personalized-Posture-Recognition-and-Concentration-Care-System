# mlkit_pose

ML Kit을 활용한 실시간 관절 인식 Flutter 앱

## 기능
- 카메라로 사람 관절 17개 실시간 인식
- 관절 연결선 시각화

## 실행 방법
1. Flutter SDK 설치
2. `flutter pub get`
3. `flutter run`
